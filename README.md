#### My alacritty config

##### Pre-requisites
- RobotoMono Nerd Font Mono -- download all ttf files, place it in ~/.local/share/fonts/ and run `fc-cache -f -v`
- zsh shell installed `sudo apt install zsh`

##### Installation
```shell
git clone --recurse-submodules --single-branch --branch popos https://github.com/sulo1337/alacritty.git ~/.config/alacritty
```
