#### My alacritty config

##### Pre-requisites
- RobotoMono Nerd Font Mono `scoop install nerd-fonts/RobotoMono-NF-Mono`

##### Installation
In Powershell:
```shell
git clone --recurse-submodules --single-branch --branch windows https://github.com/sulo1337/alacritty.git $HOME\AppData\Roaming\alacritty
```
